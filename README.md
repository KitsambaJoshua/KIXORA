# KIXORA — Full Design Package
**Tagline:** Connect. Share. Belong.  
**Brand credit:** Designed by Kitsamba Joshua

## What's included
- `assets/kixora_full_ui_design_reference.png` — your supplied KIXORA visual concept board; use this as the canonical design reference.
- `design-system.md` — palette, typography, components, spacing, and interaction guidance.
- `screen-specifications.md` — screen-by-screen layout notes for FlutterFlow implementation.
- `flutterflow-setup.md` — practical steps for using the package in FlutterFlow.
- `design-tokens.json` — reusable design tokens.
- `prototype/index.html` — a responsive, clickable visual prototype you can open in a browser.

## Important FlutterFlow limitation
This ZIP is a design handoff package, not a native FlutterFlow project export. FlutterFlow does not generally convert an arbitrary ZIP of HTML/CSS or Flutter source into editable FlutterFlow Builder pages. Use the reference board and screen specifications to recreate/import supported individual assets, or use FlutterFlow Designer's supported workflow if available in your account. The included HTML prototype is for preview and inspiration, not a deployable FlutterFlow app.

The screens are visual scaffolding only. Authentication, feeds, uploads, chat, notifications, and other live features require backend setup and implementation.
